# Muxway 管理员部署与运营确认

版本：v2026.09.16

本文件适用于部署、配置、管理、运营或实际控制 Muxway（TermRelay）实例的管理员、运营者及其授权代表。首次进入管理后台，或本文件版本发生更新后，管理员需要重新阅读并确认本文件。

本文件的目的，是让实际运营者明确自身对服务运营、上游接口使用、用户与数据处理、收费结算、安全与风控等事项承担的责任。它不替代适用法律、监管要求、上游服务条款、商业合同、隐私政策或其他应当具备的文件与手续。

## 一、运营主体与责任

1. 管理员确认自己代表当前 Muxway 实例的实际运营或控制主体，并有权进行相应的管理与配置操作。
2. 当前实例的部署、运营、推广、收费、用户管理、内容处理、数据处理、账号使用和接口调用，由实际运营主体独立负责。
3. 运营主体应根据服务器所在地、业务开展地、目标用户所在地及上游服务提供方的要求，自行评估可能适用的法律法规、监管要求、合同义务和平台规则。

## 二、上游服务与授权

1. 运营主体应阅读并持续遵守 OpenAI、Anthropic、Google 及其他实际接入服务提供方的服务条款、可接受使用政策、账号/API Key 规则、商业使用要求、支持地区、转售限制、风控要求和技术限制。
2. 不利用 Muxway 规避或协助他人规避上游服务的地区限制、访问限制、账号限制、身份验证、计费限制、风控限制、使用限制或服务条款。
3. 如业务模式涉及 API 中转、模型调用转售、额度分发、团队共享、付费调用或其他类似服务，应在具备必要授权、合同安排、资质或许可的前提下开展。

## 三、用户、内容与数据

1. 运营主体应建立与业务规模相匹配的用户管理、访问控制、滥用处理、内容安全、投诉处理和应急处置机制。
2. 对收集、存储、处理或传输的用户数据、请求内容、日志、账户信息和其他可能涉及个人信息或商业信息的数据，应采取合理的数据保护措施，并遵守适用的隐私、数据安全和个人信息保护要求。
3. 不应以调试、运营或统计为由无限期保存不必要的敏感内容；应根据业务需要设置合理的日志留存、访问权限和删除机制。

## 四、收费、支付与退款

1. 如向用户收费，运营主体应清晰展示价格、计费方式、套餐规则、余额或订阅权益、退款政策及必要的客户支持信息。
2. 支付、退款、对账、税务、发票、消费者权益和资金处理应符合适用法律法规以及所使用支付渠道的规则。
3. 共建分成、渠道结算或其他第三方收益分配应保持清晰账目和可核对记录；如相关业务受到金融、支付或资金清分规则约束，应采用符合要求的处理方式。

## 五、安全、风控与持续运营

1. 管理员应妥善保护管理员账户、服务器、数据库、API Key、OAuth 凭据、支付密钥和其他敏感凭据，不将密钥硬编码到公开仓库或泄露给无关人员。
2. 应建立与业务规模相匹配的限流、异常检测、访问控制、备份、恢复、审计和安全事件响应机制。
3. 发现账号滥用、异常调用、数据泄露、支付异常、安全漏洞或上游服务风险时，应及时采取限制、下线、修复、通知或其他必要措施。

## 六、禁止性原则

管理员确认不会利用当前实例实施或协助实施明显违法、有害、欺诈、侵权、恶意绕过安全控制、盗用账号或凭据、未经授权访问系统等行为，也不会故意为此类行为提供便利。

## 七、确认记录

管理员完成确认后，系统会保存当前条款版本、管理员账户标识、确认时间、IP 地址和 User-Agent 等必要信息，用于记录该管理员已阅读并确认当前版本。

当本文件版本更新时，系统可以要求管理员再次确认，以确保新的运营要求和风险提示被明确知悉。

## 八、确认方式

在管理后台按照页面提示阅读本文件、勾选阅读确认，并逐字输入以下确认短语，即表示管理员确认已经阅读、理解并同意本文件：

> 我已阅读、理解并同意 Muxway 管理员部署与运营确认

如对具体业务所在司法辖区的许可、备案、税务、支付、隐私或其他法律义务存在疑问，应咨询具有相应资质的专业人士。本文件本身不构成法律意见。
