Muxway 模枢：统一 AI API 接入说明

Muxway 提供统一 AI API 入口，帮助开发者通过熟悉的 SDK 和工具接入账户中可用的模型，并集中管理 API Key、用量和套餐。

信息边界：本文说明平台的一般接入方式，不构成实时模型清单、价格表、可用率或服务等级承诺。可用模型、支持的接口、价格与套餐以登录后的平台实际信息为准。

Muxway 是什么？适合哪些场景？

Muxway（模枢）是一个统一 AI API 接入与管理平台。开发者可为项目配置 API Key，使用与对应接口兼容的 SDK 发起请求，在控制台查看请求、Token 与费用记录。

适用于希望集中管理多个项目 API Key、减少不同模型接入配置成本，以及查看 AI 请求用量的开发工作流。每个账户能调用哪些模型取决于其实际权限和平台配置。

如何开始接入？

  1. 在 Muxway 注册页面创建账户并登录。
  2. 在控制台查看可使用的模型、对应接口协议以及套餐信息，然后创建 API Key。
  3. 对提供 OpenAI 兼容接口的模型，可在相应 SDK 中设置 Base URL 为 https://muxway.dev/v1，并配置你的 Muxway API Key。
  4. 从当前账户的模型列表中选择实际可用的模型名称，先执行小规模测试，再接入生产工作流。

OpenAI Python SDK 配置示例

下面的示例仅适用于账户中开放了相应 OpenAI 兼容接口的模型；请根据模型支持情况调整调用方法。

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["MUXWAY_API_KEY"],
    base_url="https://muxway.dev/v1",
)

response = client.chat.completions.create(
    model="<your-available-model>",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)

不要在前端公开代码、网页或仓库中直接写入实际 API Key。

常见问题

Muxway 支持哪些 AI 模型？

实际可用模型可能随上游服务、账户分组和平台配置调整。请登录后查看当前模型列表；不要把示例中的模型名称理解为可用性承诺。

可以使用已有的 SDK 吗？

对于平台提供相应兼容接口的模型，可以保留熟悉的 SDK 调用方式，主要调整 Base URL、密钥和模型名称。不同模型的参数、功能和兼容程度可能不同，需以实际接口测试为准。

如何区分 API Key 和套餐？

API Key 是调用凭证；套餐和账户权限决定模型及用量范围。请在控制台分别管理密钥、套餐与用量。

价格、速率和可用性是否固定？

本文不展示可能过时的实时信息。准确的模型可用性、价格和使用限制应以平台当前显示及适用服务条款为准。

如何查看使用情况？

登录后可在控制台查看请求、Token 与费用等相关使用记录；具体可见的数据受账户权限和系统配置影响。

官方入口与信息更新

官方网站：https://muxway.dev/home；接入根地址：https://muxway.dev/v1。阅读平台当前显示的信息后，再确认具体模型支持与收费规则。
